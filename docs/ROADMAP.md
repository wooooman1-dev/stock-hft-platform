# Roadmap

## Phase 1 — 완료
- 실시간 대시보드
- 10단계 호가·체결 시뮬레이터
- 호가 불균형, 체결 흐름, 스프레드, 속도, 모멘텀, 변동성
- 신호 점수와 근거 표시
- 내부 모의 시장가 주문
- 포지션·손익·주문 내역
- 수량·포지션·손실 한도와 킬 스위치
- 내부 모의 자동전략

## Phase 2A — LS증권 시세 어댑터 구현
- OAuth 접근토큰
- t1101 초기 호가 조회
- KOSPI/KOSDAQ/통합 WebSocket 호가·체결 구독
- 공통 시장 데이터 정규화
- 연결 상태 및 오류 표시
- 내부 모의매매와 실제 시세 결합

## Phase 2B — 실제 계정 검증 대기
- 사용자가 LS증권 OPEN API 및 모의투자 키 발급
- 실제 토큰 발급 검증
- 삼성전자 장중 호가·체결 검증
- 연결 단절·재접속·토큰 만료 검증
- 실제 틱·호가 저장과 거래일 리플레이

## Phase 3 — LS 모의투자 주문
- 주문 전용 BrokerOrderAdapter
- 현물주문·정정·취소
- 주문접수·체결·거부 실시간 이벤트
- 주문 idempotency와 결과 불명 처리
- 잔고·예수금 대사
- 반자동 승인 모드

## Phase 4 — 검증과 실전 경계
- 수수료·세금·슬리피지 모델 고도화
- 전략 버전 관리와 워크포워드 테스트
- 일일 손실 한도 날짜별 리셋
- 장 종료 강제 청산 정책
- 충분한 모의투자 이후 최소금액 실계좌 카나리

## Phase 5 — 한국투자증권 추가
- 공통 계약 기반 시세 어댑터
- 모의투자 주문 어댑터
- 증권사별 지연·누락·체결 품질 비교
