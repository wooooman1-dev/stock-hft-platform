# Roadmap

## Phase 1 — 시장 분석 기반 완료

- 실시간 대시보드
- 10단계 호가·체결 시뮬레이터
- 호가 불균형, 체결 흐름, 스프레드, 속도, 모멘텀, 변동성
- 신호 점수와 근거 표시
- 기본 리스크 제한과 킬 스위치
- 기본 모의 자동전략

## Phase 2A — 내부 주문 상태·체결 기반 구현

- 시장가 IOC
- 지정가 GTC
- 표시호가 다단계 체결과 평균 체결가
- 부분 체결과 미체결 잔량 처리
- 지정가 주문 취소
- `clientOrderId` 중복 방지
- 열린 주문 현금·수량 예약
- 주문 이벤트와 개별 체결 기록

## Phase 2B — 자동전략 설정·위험청산 구현

- 전략 설정 화면과 서버 저장
- 손절
- 익절
- 트레일링 스톱
- 최대 보유시간
- 포지션 최초 진입시각과 진입 후 최고가 추적
- 전략 청산 전 열린 주문 취소
- 전체 보유수량 시장가 IOC 청산
- 서버 재시작 시 자동전략 OFF

## Phase 2C-1 — 실행 저널 구현

- 주문 생성 append-only 기록
- 주문 상태 변경 append-only 기록
- 체결 상세 append-only 기록
- 모의계좌 초기화 기록
- JSONL 연속 순번과 시작 시 전체 검증
- 이벤트 append 후 fsync
- 기록 실패 시 킬 스위치 ON·자동전략 OFF
- API 키·시크릿·토큰·실제 계좌번호 기록 금지

## Phase 2C-2 — 후속 위험 기반

- 연속 손실 제한
- 하루 거래횟수 제한
- 장 종료 청산 정책
- 실행 저널 기반 성과 통계와 최대 낙폭
- 실제 호가·체결 리플레이
- 실행 저널 백업·압축·보관주기

## Phase 3A — 한국투자 실전 시세 전용 REST 기반

- 공식 실전 도메인·토큰·현재가 규격 확정
- 명시적 `PROD_READ_ONLY` 활성화 모드
- App Key·App Secret 전용 로컬 자격정보 경계
- 계좌번호 및 임의 추가 필드 거절
- OAuth 접근토큰 로컬 캐시와 만료 전 재사용
- 동시 토큰 요청 중복 방지
- 국내주식 현재가 조회와 공통 응답 정규화
- 로컬 루프백 전용 상태·현재가 API
- 주문·정정·취소·계좌·잔고 경로 미구현 및 404 차단
- 외부 오류의 키·시크릿·토큰 마스킹
- 사용자 환경 실제 토큰·현재가 검증 전

## Phase 3B — 한국투자 실시간 시세

- WebSocket 승인키
- 실제 호가·체결 정규화
- 공통 MarketDataAdapter
- 누락·순서·지연 검사
- 연결 단절과 지수 백오프 재연결
- 실제 틱·호가 append-only 저장
- 실시간 시세와 REST 스냅샷 대사
- 기존 분석 런타임 전환 전 리플레이 검증

## Phase 4 — 한국투자증권 모의투자 주문

- 모의투자 App Key 별도 발급
- 공통 OrderAdapter
- 주문·정정·취소
- 접수·부분체결·전량체결·거절 상태 정규화
- 모의계좌 잔고·예수금 대사
- 주문 결과 불명 처리
- 내부 체결모델과 증권사 모의체결 결과 비교

## Phase 5 — 검증과 실전 경계

- 증권사별 수수료·세금 반영
- 전략 버전 관리
- 워크포워드 테스트
- 반자동 승인 모드
- 충분한 모의투자 검증
- 사용자 별도 승인 후 최소금액 실계좌 카나리 검토
