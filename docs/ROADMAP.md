# Roadmap

## Phase 1 — 시장 분석 기반 완료

- 실시간 대시보드
- 10단계 호가·체결 시뮬레이터
- 호가 불균형, 체결 흐름, 스프레드, 속도, 모멘텀, 변동성
- 신호 점수와 근거 표시
- 기본 리스크 제한과 킬 스위치
- 기본 모의 자동전략

## Phase 2A — 내부 주문 상태·체결 기반 구현

- 시장가 IOC
- 지정가 GTC
- 표시호가 다단계 체결과 평균 체결가
- 부분 체결과 미체결 잔량 처리
- 지정가 주문 취소
- `clientOrderId` 중복 방지
- 열린 주문 현금·수량 예약
- 주문 이벤트와 개별 체결 기록

## Phase 2B — 다음 구현 대상

- 전략 설정 화면과 서버 저장
- 손절·익절·최대 보유시간
- 연속 손실·하루 거래횟수 제한
- 장 종료 청산 정책
- 주문·체결 append-only 영구 로그
- 성과 통계와 최대 낙폭
- 실제 호가·체결 리플레이

## Phase 3 — 한국투자증권 시세

- 공식 API 문서와 샘플 응답 확정
- 공통 MarketDataAdapter
- OAuth 토큰 및 WebSocket 승인키
- 실제 호가·체결 정규화
- 누락·순서·지연·재연결 검사
- 실제 틱·호가 저장

## Phase 4 — 한국투자증권 모의투자 주문

- 공통 OrderAdapter
- 주문·정정·취소
- 접수·부분체결·전량체결·거절 상태 정규화
- 모의계좌 잔고·예수금 대사
- 주문 결과 불명 처리
- 내부 체결모델과 증권사 모의체결 결과 비교

## Phase 5 — 검증과 실전 경계

- 증권사별 수수료·세금 반영
- 전략 버전 관리
- 워크포워드 테스트
- 반자동 승인 모드
- 충분한 모의투자 검증
- 사용자 별도 승인 후 최소금액 실계좌 카나리 검토
