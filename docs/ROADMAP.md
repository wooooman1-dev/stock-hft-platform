# Roadmap

## Phase 1 — 완료된 기반
- 실시간 WebSocket 대시보드
- 10단계 호가·체결 시뮬레이터
- 호가 불균형, 가중 불균형, 체결 흐름, 스프레드, 속도, 모멘텀, 변동성
- 신호 점수와 근거 표시
- 모의 시장가 주문
- 포지션·손익·주문 내역
- 수량·포지션·손실 한도와 킬 스위치
- 모의 자동전략

## Phase 2 — 실제 데이터
- 증권사 선정 및 개발자 계정 준비
- WebSocket 시세 어댑터
- 종목 검색과 감시 목록
- 실제 틱·호가 저장
- 거래일 리플레이

## Phase 3 — 검증
- 수수료·세금·슬리피지 모델 고도화
- 전략 버전 관리
- 워크포워드 테스트
- 지연시간·누락 이벤트·재연결 검사

## Phase 4 — 주문 연결
- 반자동 주문 승인
- 모의투자 계좌 주문
- 실전 최소금액 카나리
- 주문 결과 불명 처리와 재조정
