# PulseHFT

실시간 호가·체결 기반 초단타 분석과 모의 자동매매를 하나의 서버 중심 구조로 구현한 첫 버전입니다.

> 현재는 **SIMULATION / PAPER ONLY**입니다. 실제 계좌 주문은 연결되어 있지 않습니다.

## 포함 기능

- 10단계 호가창과 실시간 체결
- 1초봉 가격 차트
- 가중 호가 불균형, 체결 흐름, 거래 속도, 스프레드, 모멘텀, 변동성
- 매수·매도·관망 신호 점수와 판단 근거
- 모의 시장가 주문과 손익 계산
- 모의 자동전략
- 최대 주문·최대 포지션·일일 손실 한도
- 킬 스위치
- 서버 전송 이벤트(SSE) 기반 실시간 대시보드
- 외부 패키지 의존성 없음

## 실행

Node.js 22 이상만 있으면 됩니다. `npm install`은 필요하지 않습니다.

```bash
npm start
```

브라우저에서 `http://localhost:8787`을 엽니다.

개발 중 파일 변경 자동 재시작:

```bash
npm run dev
```

검증:

```bash
npm run check
```

## 디렉터리

```text
public/   브라우저 대시보드
server/   시장 데이터·분석·모의 주문·리스크 엔진
docs/     아키텍처와 단계별 로드맵
```

실제 증권사 연동 경계와 안전 설계는 `docs/ARCHITECTURE.md`를 확인하세요.
